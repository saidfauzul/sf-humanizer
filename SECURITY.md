# Security Policy

## Supported versions

sf-humanizer is pre-alpha. Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please do not open a public issue. Report privately through a [GitHub security advisory](https://github.com/saidfauzul/sf-humanizer/security/advisories/new).

Reports are especially welcome for:

- prompt injection paths through skill files or samples;
- scripts in the skill that read or send data unexpectedly;
- samples containing personal or confidential information.

If a sample exposes personal data, say which file is affected but do not repeat the data in your report. You can expect an initial response within seven days.
