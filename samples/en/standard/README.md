# Standard (English)

> Draft register definition.

Neutral general-audience English: explanatory articles, documentation, web copy. Plain and clear, neither stiff nor chatty.

Features of the register:

- The main point comes first.
- The reader is addressed as "you" where that fits.
- Short, everyday words, with terms of art explained or left as they are.
- Varied sentence length, with few contractions.

Text types covered: web content, explanatory articles, FAQs, public announcements and short public reports.

- `good/`: examples of good human writing.
- `pairs/`: before-and-after rewrite pairs.
