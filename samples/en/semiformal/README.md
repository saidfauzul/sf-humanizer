# Semiformal (English)

> Draft register definition.

Professional writing with a lighter touch: internal memos, briefings, work articles. Standard grammar, shorter sentences, and occasional contractions.

Features of this register:

- Standard grammar with a lighter touch.
- Shorter sentences mixed with longer ones, and occasional contractions.
- A clear next step, owner or decision.
- Plain verbs in place of official phrasing.

Text types covered:

- Internal memos
- Meeting notes
- Project updates and briefings

- `good/`: examples of good human writing.
- `pairs/`: before-and-after rewrite pairs.

The sample format is described in [CONTRIBUTING.md](../../../CONTRIBUTING.md).
