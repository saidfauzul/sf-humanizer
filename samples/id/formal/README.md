# Formal (Bahasa Indonesia)

> Draf definisi register.

Bahasa resmi kedinasan dan regulasi: surat dinas, nota dinas, SOP, peraturan, laporan pengadaan. Mengikuti PUEBI/EYD, kalimat lengkap, tanpa bahasa percakapan. Istilah teknis dan rujukan pasal dipertahankan persis.

- `good/`: contoh tulisan manusia yang baik.
- `pairs/`: pasangan teks sebelum dan sesudah penulisan ulang.

Format sampel dijelaskan di [CONTRIBUTING.md](../../../CONTRIBUTING.md).
