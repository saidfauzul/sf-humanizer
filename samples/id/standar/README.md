# Standar (Bahasa Indonesia)

> Draf definisi register.

Bahasa Indonesia umum yang baku dan netral: artikel, penjelasan, dokumentasi untuk pembaca luas. Tidak sekaku bahasa kedinasan dan tidak bernada percakapan.

- `good/`: contoh tulisan manusia yang baik.
- `pairs/`: pasangan teks sebelum dan sesudah penulisan ulang.

Format sampel dijelaskan di [CONTRIBUTING.md](../../../CONTRIBUTING.md).
