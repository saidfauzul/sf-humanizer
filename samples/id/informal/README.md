# Informal (Bahasa Indonesia)

> Draf definisi register.

Bahasa sehari-hari: pesan ke rekan, unggahan media sosial, catatan pribadi. Boleh memakai bentuk tidak baku dan kata seperti "nggak" atau "sih" sejauh wajar.

- `good/`: contoh tulisan manusia yang baik.
- `pairs/`: pasangan teks sebelum dan sesudah penulisan ulang.
