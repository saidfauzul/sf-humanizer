# Informal (Bahasa Indonesia)

> Draf definisi register.

Bahasa sehari-hari: pesan ke rekan, unggahan media sosial, catatan pribadi. Boleh memakai bentuk tidak baku dan kata seperti "nggak" atau "sih" sejauh wajar.

Ciri register:

- Kalimat mengikuti cara orang bicara, panjangnya tidak seragam, dan boleh memakai partikel seperti "ya", "kok", "nih".
- Sapaan langsung ("teman-teman", "kamu"), tanpa formula surat dinas.
- Angka, tanggal, nama, dan istilah terkunci tetap ditulis persis walaupun nadanya santai.

Jenis teks: pesan grup kerja, pengumuman santai, unggahan media sosial instansi.

- `good/`: contoh tulisan manusia yang baik.
- `pairs/`: pasangan teks sebelum dan sesudah penulisan ulang.
